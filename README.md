# CGT-215-Lab-07-langsta
A program that sets 4 walls on all sides and a center block where a ball is shot with an impulse.
The impulse can be modified in the code.
Every time the ball hits a wall(in this case, the ceiling and floor are also referred to as walls), it reports a thud.
Every time the ball hits the center block, it reports a bang, and once the bang integer reaches 2, the program exits
